# Code of Conduct

This project follows the Contributor Covenant, version 2.1. Everyone in Trooth's open-source spaces is expected to be respectful, direct, and kind.

Unacceptable behavior includes harassment, personal attacks, and anything that would be inappropriate in a professional setting.

Report concerns privately to conduct@trooth.co. Reports are handled confidentially. Maintainers who do not uphold this code may be removed.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
