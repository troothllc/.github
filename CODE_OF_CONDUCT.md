# Code of Conduct

Trooth operates the Trooth Network: one public, signed, machine-readable record per company. It is Trooth's only product and it is free. These repositories are the open part of it: the readers, the evaluation harnesses and the descriptions of the public interfaces. Everything below applies in all of them, and in the issues, pull requests and discussions attached to them.

## The standard

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). That document is the standard; this file does not restate it and does not narrow it.

In plain terms: be respectful and be direct. Disagree with the argument. Unacceptable behavior includes harassment, personal attacks, and anything that would be out of place in a professional setting.

## Reporting

Report privately to **hello@trooth.co**.

There is no separate conduct alias. Earlier copies of this file named `conduct@trooth.co`, an address that appears in no mail routing, no DNS record and nowhere on trooth.co, so a report sent to it may have gone nowhere. The address above is the one the organization profile publishes and the one that is read.

Reports are handled confidentially. What you can expect:

- Acknowledgment that the report arrived.
- A decision, and what was done about it.

What you should not expect, because it does not exist: a committee, an appeals board, or a second person to escalate to. Trooth is one person today. The organization's own `CODEOWNERS` files point at a `@troothllc/maintainers` team that has not been created yet, which is the same fact seen from the other side. When there is a second person, this section changes and the change will be visible in this file's history.

## Enforcement

A maintainer who does not uphold this code may be removed from the project. A contributor who does not may have their contributions removed and their participation ended. Both are decisions this project can actually carry out, which is why they are the two named here.
